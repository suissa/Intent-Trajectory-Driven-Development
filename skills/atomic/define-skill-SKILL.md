# Atomic Skill — Define Skill

## Purpose
Create a reusable executable semantic capability.

## When
Use when a Behavior step can be independently invoked and verified.

## Procedure
Define inputs, outputs, preconditions, decision rules, invariants and evidence.

## Output
An Atomic Skill contract.

## Invariant
A Skill MUST preserve the semantics of its source Behavior.
