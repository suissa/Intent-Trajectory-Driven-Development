# Atomic Skill — Bind Actor

## Purpose
Define who is authorized to perform each capability.

## When
Use when behavior crosses actor or authority boundaries.

## Procedure
1. Enumerate semantic actors.
2. Map capabilities to actors.
3. Reject unauthorized actions.
4. Preserve authority through execution.

## Output
Actor/capability map.

## Invariant
Technical possibility MUST NOT imply semantic authorization.
