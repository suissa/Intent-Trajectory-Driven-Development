# Atomic Skill — Define Contract

## Purpose
Remove ambiguity from semantic boundaries.

## When
Use when inputs, outputs, invariants or failures need exact definition.

## Procedure
Define inputs, outputs, preconditions, postconditions, invariants and permitted errors.

## Output
A semantic Contract.

## Invariant
A Contract MUST constrain the Behavior without changing its meaning.
