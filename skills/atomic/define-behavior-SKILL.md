# Atomic Skill — Define Behavior

## Purpose
Describe what must happen to realize an Intent.

## When
Use after Intent is known and before implementation.

## Procedure
Define ordered behavior without HTTP, database, provider or framework coupling.

## Output
A behavior flow whose steps can later be mapped to Skills.

## Invariant
Behavior MUST preserve the meaning of Intent and Destination.
