# Atomic Skill — Define Destination

## Purpose
Define the business outcome that determines what completion means.

## When
Use before technical design when the outcome is unclear.

## Input
Business problem, desired outcome, stakeholders and completion conditions.

## Procedure
1. State the outcome in business terms.
2. List explicit completion conditions.
3. Define the evidence required for completion.
4. Reject technology as the destination.

## Output
A Destination/Destiny declaration.

## Invariant
Implementation choices MUST remain subordinate to the Destination.
