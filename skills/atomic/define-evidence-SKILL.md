# Atomic Skill — Define Evidence

## Purpose
Define observable facts that prove behavior occurred.

## When
Use while specifying Behavior and before implementation.

## Procedure
For every important behavior, define the observable evidence that can prove success, repetition, failure or transition.

## Output
An evidence model.

## Invariant
Evidence MUST describe facts, not merely implementation logs.
