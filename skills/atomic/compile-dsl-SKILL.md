# Atomic Skill — Compile DSL

## Purpose
Compress established semantics into the T-DD DSL.

## When
Use only after the semantic stages are defined.

## Procedure
Map Destination, Intent, required information, Behavior, State, Actor, Evidence and forbidden conditions to the DSL symbols.

## Output
A declarative semantic source such as `.itdsl`.

## Invariant
The DSL MUST NOT introduce meaning that does not exist in the semantic model.
